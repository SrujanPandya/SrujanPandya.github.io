# Design experiments

These files are preserved from the original repository because they document earlier layout and palette exploration. They are **not imported by the production React application**.

- `palette-switcher.html` — palette exploration tool, including the Academic Parchment direction that informed the new light theme.
- `project_page.js` — early detail-page prototype containing placeholder quantum-physics copy. Do not treat that copy as portfolio content.
- `research_portfolio_index.js` — earlier single-page portfolio prototype.

Keeping these out of the repository root makes the deployed architecture easier to understand while retaining the design history.
